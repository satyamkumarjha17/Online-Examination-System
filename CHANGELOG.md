# Changelog

## Web edition 1.0

- Replaced the desktop Swing screens with a responsive browser interface.
- Reused the original Java, Aptitude and General Knowledge question bank.
- Added server-side exam sessions, timer enforcement, scoring and answer review.
- Added an administrator PIN gate and result-record view.
- Added CSV persistence, Docker packaging and Render deployment notes.
- Reconciled documentation to the actual 30-question banks and three-person team listed in the supplied report.


## Update: assessment workflow and palette

- Assessment launches in a new browser tab after confirmation; the portal stays in the original tab.
- Question palette now has five mutually exclusive states with distinct colours and accessible labels: Answered, Current, Seen/unanswered, Review and Not visited.
- Removed individual names from public project documentation and sample UI text.
- Added an independent SHL-inspired assessment design direction without using SHL branding or assets.
